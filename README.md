# CampusFlow

TP de programmation mobile, Master 1 MSI. CampusFlow est une application de suivi des cours, des échéances et des tâches d'un étudiant, construite séance après séance : de la décision de plateforme jusqu'à une application Flutter connectée à une API avec connexion.

| Séance | Sujet | Dossier |
|---|---|---|
| 1 | Écosystème mobile : fiche comparative, autopsie de Windows Phone, décision | `docs/seance-1-plateforme` |
| 2 | UX/UI : persona, parcours, wireframes, design system | `docs/seance-2-conception` |
| 3 | Dart : modèles, `fromJson`, dépôt simulé, tests | `seance-3-models` |
| 4 | Projet Flutter, thème, package et image | `seance-4-init` |
| 5 | Écrans Échéances, Détail, Formulaire, tablette | `seance-5-screens` |
| 6 | go_router, Riverpod, filtres | `seance-6-riverpod` |
| 7 | API json-server, Dio, repositories, connexion par jeton | `seance-7-api` |
| 3 à 6 | Exercices individuels | `exercices` |

Chaque dossier de code garde l'état du projet à la fin de la séance. L'application complète est dans `seance-7-api` (voir son README pour la lancer).

Le code est en anglais, les documents de conception en français. Les adresses (`/taches`, `/cours`, `/profil`) sont celles de l'énoncé.

Les applications ont été testées dans le navigateur et avec `flutter test`. Je n'ai pas encore d'émulateur Android installé.
